## 常微分方程式と初期値問題

### 変化率・未知関数・独立変数

時刻$t$におけるある量を$y(t)$と書く．
例えば，$t$を日数，$y(t)$をある物質の質量とすると，$y(0)=100$は「0日目の質量が100 g」という意味になる．

短い時間$\Delta t$の間の**平均変化率**は，

$$
\frac{y(t+\Delta t)-y(t)}{\Delta t}
$$

で与えられる．
これに対し，**瞬間の変化率**は微分

$$
\frac{dy}{dt}(t)
=
\lim_{\Delta t\to 0}
\frac{y(t+\Delta t)-y(t)}{\Delta t}
$$

で表す．

| 記号 | 役割 | 今回の例と単位 |
| --- | --- | --- |
| $t$ | 独立変数 | 時刻［日］ |
| $y(t)$ | 求めたい未知関数・状態変数 | 質量［g］ |
| $dy/dt$ | $y$の瞬間の変化率 | 質量の変化率［g/日］ |
| $r$ | 変化の仕方を決めるパラメタ | 比例係数［1/日］ |

$y$が大きいことと，$dy/dt$が大きいことは異なる．
例えば，100 gの物質が変化しなければ$dy/dt=0$であり，10 gの物質が1日当たり2 gの速さで増えていれば，その時点の$dy/dt=2$である．

### 微分方程式が表すもの

**微分方程式**は，未知関数とその導関数の関係を表す方程式である．
そのうち，未知関数が1つの独立変数に依存し，その変数による微分を含むものを**常微分方程式**と呼ぶ．

今回は，1階の常微分方程式を

$$
\frac{dy}{dt}=f(t,y)
$$

という形で扱う．
右辺の$f(t,y)$は，時刻$t$とその時点の状態$y$から変化率を決める関数である．

| 現象の説明 | 微分方程式 | 変化の特徴 |
| --- | --- | --- |
| 毎日，一定量$a$ずつ増える | $dy/dt=a$ | 現在の量によらず，同じ速さで増える |
| 現在の量に比例する速さで増える | $dy/dt=ry$（$r>0$） | 現在の量が多いほど増加が速い |
| 現在の量に比例する速さで減る | $dy/dt=-ky$（$k>0$） | 現在の量が多いほど減少量の大きさも大きい |

右辺に$t$が直接現れない場合もある．
例えば$f(t,y)=ry$では，変化率は現在の量$y$に依存する．

### 微分方程式と初期条件の役割

「毎日10 gずつ増える」という規則だけでは，5日後の質量は決まらない．
最初に100 gあれば150 gになり，最初に200 gあれば250 gになる．

そこで，計算を始める時刻$t_0$における値$y_0$を指定する．
この条件

$$
y(t_0)=y_0
$$

を**初期条件**と呼ぶ．
微分方程式と初期条件を組み合わせた

$$
\frac{dy}{dt}=f(t,y),
\qquad
y(t_0)=y_0
$$

が，今回扱う**初期値問題**である．

「解を求める」とは，この微分方程式と初期条件の両方を満たす関数$y(t)$を求めることである．

```{tip} 初期値とパラメタを区別する
初期値$y_0$は「どの状態から始めるか」，パラメタ$r$は「どのような規則で変化するか」を指定する．
どちらもグラフを変えるが，モデルの中での役割は異なる．

初期時刻$t_0$は必ずしも0ではない．
$t_0=2$なら，初期条件は$y(2)=y_0$と書く．
```

## 指数的な増加・減衰のモデル

### 変化率からの定式化とパラメタの単位

ここからは，「変化率が現在の量に比例する」という仮定を置く．
一定の比例係数$r$を用いると，

$$
\frac{dy}{dt}=ry,
\qquad
y(t_0)=y_0
$$

と書ける．

$y$の単位がg，$t$の単位が日なら，左辺$dy/dt$の単位はg/日である．
両辺の単位をそろえるため，$r$の単位は1/日となる．

例えば$r=0.2$［1/日］のとき，$y=100$ gの時点では$dy/dt=20$ g/日，$y=200$ gの時点では$dy/dt=40$ g/日となる．
一定なのは増加量そのものではなく，$y>0$に対する**相対的な瞬間の変化率**

$$
\frac{1}{y}\frac{dy}{dt}=r
$$

である．

### 解析解と初期条件の関係

この初期値問題の解は，

$$
\boxed{y(t)=y_0 e^{r(t-t_0)}}
$$

である．
このように，数式として表された解をここでは**解析解**と呼ぶ．

まず，微分方程式を満たすことを確かめる．
$r$が定数であることを使って微分すると，

$$
\frac{d}{dt}\left(y_0 e^{r(t-t_0)}\right)
=
r y_0 e^{r(t-t_0)}
=
r y(t)
$$

となる．
次に$t=t_0$を代入すると，

$$
y(t_0)=y_0e^0=y_0
$$

となり，初期条件も満たす．

指数の中の$r(t-t_0)$は，［1/日］×［日］なので単位を持たない．
数式の形だけでなく，この単位の対応も確認すること．

```{dropdown} 補足：解析解を導く

$y>0$の場合，変数分離によって

$$
\frac{1}{y}\,dy=r\,dt
$$

となる．
初期時刻から時刻$t$まで積分すると，

$$
\int_{y_0}^{y(t)}\frac{1}{u}\,du
=
\int_{t_0}^{t}r\,ds
$$

より，

$$
\log\frac{y(t)}{y_0}=r(t-t_0)
$$

を得る．
両辺の指数を取れば$y(t)=y_0e^{r(t-t_0)}$となる．

この導出は$y_0>0$の場合を扱っている．
$y_0=0$では割り算をせず，$y(t)=0$を直接代入して解であることを確認できる．
```

### パラメタの符号と解の挙動

以下では，質量を表すため$y_0>0$，$t\geq t_0$とする．

| パラメタ | 解の挙動 | 初期時刻の変化率 |
| --- | --- | --- |
| $r>0$ | 指数的に増加する | $ry_0>0$ |
| $r=0$ | $y(t)=y_0$のまま変化しない | $0$ |
| $r<0$ | 正の値を保ちながら0へ近づく | $ry_0<0$ |

例えば，

$$
\frac{dy}{dt}=0.2y,
\qquad
y(0)=100
$$

の解は$y(t)=100e^{0.2t}$である．
5日後と10日後の値は，

$$
y(5)=100e\approx271.83,
\qquad
y(10)=100e^2\approx738.91
$$

となる．

```{tip} $r=0.2$は「1日ごとに厳密に20%増える」と同じではない
このモデルで1日後の量は$e^{0.2}\approx1.2214$倍となるため，1日間の増加率は約22.14%である．

「1日ごとに20%増える」という離散的な規則なら，整数日での値は$y_n=y_0(1.2)^n$となる．
これと整数日の値を一致させる連続時間モデルの係数は$r=\log(1.2)$［1/日］である．

瞬間の変化率と，一定期間内の増加率を区別することは，後半で観測データをモデルへ対応づける際にも必要になる．
```

### モデルの仮定と限界

今回のモデルでは，比例係数$r$が時間によらず一定で，変化率が$y$だけで決まると仮定している．
また，増加を抑える資源の不足や，外部からの流入・流出は含めていない．

したがって，$r>0$のモデルが長時間にわたって増え続けることは，その仮定から導かれた結果である．
実際の対象が同じように増え続けるとは限らない．
第6回では，増加が抑えられる仕組みも含めたモデルを扱う．

## 時間格子と解析解の可視化

### 初期値・計算区間・時間格子の設定

微分方程式の解$y(t)$は連続的な時間に対して定義されるが，コンピュータでは有限個の時刻を選んで値を計算する．
計算区間$[t_0,T]$を$N$等分した

$$
t_n=t_0+nh,
\qquad
h=\frac{T-t_0}{N},
\qquad
n=0,1,\ldots,N
$$

を，ここでは**時間格子**と呼ぶ．
$h$は時間の刻み幅である．

| 設定 | 今回の値 |
| --- | --- |
| 初期時刻$t_0$ | 0日 |
| 終了時刻$T$ | 10日 |
| 初期値$y_0$ | 100 g |
| パラメタ$r$ | 0.2［1/日］ |
| 分割数$N$ | 100 |
| 刻み幅$h$ | 0.1日 |
| 時刻の個数 | $N+1=101$個 |

端点を両方含めると，時刻の個数は区間の個数より1つ多くなる．
NumPyの`np.linspace(t0, T, N + 1)`を使うと，この101個の時刻を作成できる．
`linspace`の第3引数は刻み幅ではなく，**点の個数**である．
詳しくは[NumPy公式ドキュメント：linspace](https://numpy.org/doc/stable/reference/generated/numpy.linspace.html)を参照すること．

### 解析解を計算して図へ保存する

````{note} 演習2：指数的な増加を可視化する

Notebookに「演習2：解析解の可視化」という見出しを作り，演習0のセルに続けて以下を実行せよ．

**セル1：計算条件と解析解を定義する**

```python
t0 = 0.0
T = 10.0
y0 = 100.0
r = 0.2
N = 100

t = np.linspace(t0, T, N + 1)
h = (T - t0) / N


def exponential_solution(t, y0, r, t0=0.0):
    """dy/dt = r*y, y(t0) = y0 の解析解を返す．"""
    return y0 * np.exp(r * (t - t0))


y = exponential_solution(t, y0, r, t0)

print(f"時刻の個数: {len(t)}")
print(f"刻み幅: {h:.2f} 日")
print(f"初期値: {y[0]:.2f} g")
print(f"5日後: {exponential_solution(5.0, y0, r, t0):.2f} g")
print(f"10日後: {y[-1]:.2f} g")
```
````

```{tip} 解析解の評価と数値解法の違い
今回は，各時刻$t_n$を解析解$y_0e^{r(t_n-t_0)}$に代入している．
前の時刻の近似値から次の近似値を求める計算は行っていない．

したがって，今回の$h$は主に「グラフを描くために値を計算する間隔」を指定する．
次回以降の数値解法では，$h$が時間更新の近似誤差や安定性にも関わる．
なお，解析解への代入にも，コンピュータの丸め誤差は生じる．
```

\frac{y_{0,B}}{y_{0,A}}
$$

```python
from pathlib import Path

import numpy as np
import matplotlib.pyplot as plt


def exponential_solution(t, y0, r, t0=0.0):
    """dy/dt = r*y, y(t0) = y0 の解析解を返す．"""
    return y0 * np.exp(r * (t - t0))


def main():
    # srcの1つ上を，第1回の作業フォルダとして扱う．
    project_dir = Path(__file__).resolve().parent.parent
    figure_dir = project_dir / "reports" / "figures"
    figure_dir.mkdir(parents=True, exist_ok=True)

    t0 = 0.0
    T = 10.0
    y0 = 100.0
    r = 0.2
    N = 100

    t = np.linspace(t0, T, N + 1)
    y = exponential_solution(t, y0, r, t0)

    fig, ax = plt.subplots(figsize=(8, 4.5))
    ax.plot(t, y, label=f"y0={y0:g}, r={r:g} /day")
    ax.set_title("Exponential growth")
    ax.set_xlabel("Time [day]")
    ax.set_ylabel("Mass [g]")
    ax.grid(alpha=0.3)
    ax.legend()

    fig.tight_layout()
    output_path = figure_dir / "exponential_growth.png"
    fig.savefig(output_path, dpi=150)
    plt.close(fig)

    print(f"Final value: {y[-1]:.2f} g")
    print("saved:", output_path)


if __name__ == "__main__":
    main()
```

### 次回への準備

次回は[陽解法と安定性](./2_explicit_methods.md)を扱う．
今回のように解析解が分かるとは限らないため，現在の値と変化率から，短い時間だけ先の値を近似する方法を考える．

$$
\text{少し先の値}
\approx
\text{現在の値}
+
\text{現在の変化率}\times\text{短い時間}
$$

復習では，$dy/dt=ry$の右辺を計算することと，解$y(t)=y_0e^{r(t-t_0)}$を計算することの違いを，自分の言葉で説明しておくこと．

```{note} 発展問題1：初期時刻が0でない場合

初期値問題

\frac{dy}{dt}=0.2y,
\qquad
y(3)=100
$$

を，$3\leq t\leq13$で考える．

1. 解析解を書き，初期条件を満たすことを確認せよ
2. 演習2のコードを変更してグラフを描け
```

```{dropdown} 発展問題1の確認

解析解は$y(t)=100e^{0.2(t-3)}$である．
$y(3)=100$，$y(10)=100e^{1.4}\approx405.52$ gとなる．
初期時刻から10日後は$t=13$なので，$y(13)=100e^2\approx738.91$ gである．

$100e^{0.2t}$では$t=3$において約182.21 gとなり，初期条件を満たさない．
```

```{note} 発展問題2：半分になるまでの時間

$r=-0.15$［1/日］の減衰モデルについて，初期値の半分になるまでの時間$\tau$を求めよ．

1. $y(t_0+\tau)=y_0/2$を解析解に代入し，$\tau$を求める式を導け
2. $\tau$をPythonで計算せよ．自然対数には`np.log`を用いる
3. $y_0=80$ gと$y_0=160$ gで，半分になるまでの時間が変わるか確認せよ
```

```{dropdown} 発展問題2の確認

$y_0>0$として$y_0e^{r\tau}=y_0/2$から，

$$
\tau=\frac{\log(1/2)}{r}
=\frac{\log 2}{0.15}
\approx4.62\ \text{日}
$$

となる．
$y_0$が式から消えるので，このモデルでは初期値によらず同じ時間で半分になる．
```

```{note} 発展問題3：時間の単位を変える

演習2のモデルでは，$r=0.2$［1/日］としていた．
時間の単位を「時間」に変更し，同じ現象を表すモデルを書け．

1. 新しいパラメタの値と単位を求めよ
2. 計算区間を0〜240時間に変更してグラフを描け
3. 240時間後の値が，元のモデルの10日後の値と一致することを確認せよ
```

```{dropdown} 発展問題3の確認

経過時間を時間単位で$s=24t$とすると，

$$
\frac{dy}{ds}
=
\frac{dy}{dt}\frac{dt}{ds}
=
\frac{0.2}{24}y
$$

となる．
新しい係数は$0.2/24$［1/時間］である．演習2と同じ初期値100 gを用いると，

$$
y(240)=100e^{(0.2/24)\times240}=100e^2
$$

となる．
単位を変えた際は，時間の数値とパラメタを対応させて変換する必要がある．
```
