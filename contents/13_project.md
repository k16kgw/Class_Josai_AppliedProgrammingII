## 題材の決め方

題材の決め方には2つの経路がある．
どちらから始めてもよいが，最終的には両方の条件，すなわち必要なデータを取得できることと，対象現象の変化率を仮定に基づいて定式化できることを満たす必要がある．

### 経路A：データを先に選ぶ

応用プログラミングIで経験した方法である．
公的機関のサイトで時系列データを見つけ，そのデータが表す現象について仮定を置き，モデルを作る．

**例：訪日外客数**

1. JNTOの訪日外客統計に，2003年以降の月別の訪日外客数がある．
2. 状態変数を訪日外客数の月次水準の連続時間近似 $x(t)$ とし，月別集計値を月中央の $x(t_i)$ に対応させる近似を明示する．
3. 訪日外客数の月次水準の変化率は，長期トレンドと年周期成分を含む目標値との差に比例すると仮定する．第9回の $x' = -\lambda(x - g(t))$ の形になる．
4. 推定するパラメタは，緩和の速さ，傾向の傾き，季節変動の振幅と位相である．
5. 2020年以降の急減は周期モデルでは説明できないので，残差として現れる．これを「限界」の節で考察する．

経路Aの利点は，データの存在が最初から保証されていることである．
弱点は，データに合わせてモデルを後から考えるため，モデルの仮定が現象の説明として弱くなりやすいことである．
観測される量を定義し，その変化を生じさせる過程について仮定を記述する．

### 経路B：現象とモデルから必要なデータを逆算する

説明したい現象と，それを表す微分方程式をまず考え，その式の状態変数，パラメタ，外部入力に対応するデータを探す．

**例：新製品の普及**

1. 製品やサービスが既存利用者から未利用者への情報伝達によって普及する過程に関心がある．
2. 対象集団の大きさを $K$ とし，再利用や離脱を無視して状態変数を累積利用者数 $N(t)$ とする．新規利用者の発生率が $N(t)$ と未利用者数 $K-N(t)$ の積に比例すると仮定する．すると $N' = rN(1 - N/K)$ というLogisticモデル（第4回）になる．$K$ は最終的な利用者の上限である．
3. 必要なデータは累積利用者数の時系列である．候補として，総務省の通信利用動向調査におけるサービスの利用率，携帯電話やスマートフォンの契約数の推移などが考えられる（提供元と入手可否は要確認）．
4. データの頻度が年次なら点の数が少ないので，パラメタが2つ以上のモデルには注意が必要である（第5回の識別可能性）．
5. 契約数は利用者数とは異なる．1人が複数契約する場合があり，時点ごとの有効契約数は解約によって減少する．累積新規契約数と有効契約数も区別する．観測量と状態変数の対応を仮定として明示する．

経路Bの利点は，モデルの仮定が現象の説明としてはっきりしていることである．
弱点は，必要なデータが公開されていない，あるいは頻度や期間が足りないことが多い点である．
データが見つからなければ，状態変数の定義を変えるか，別の現象に切り替える．

```{tip} 2つの経路を往復する
実際には，経路Aで見つけたデータから現象を考え，経路Bで必要なデータを洗い直す，という往復になる．
モデルの構築，計算，データとの比較，残差の要因の検討，仮定の見直しという反復は，題材選びの段階から始まっている．
```

### 向いている題材と向かない題材

この授業のモデルは，時間とともに連続的に変わる量の変化率を式で表す，決定論的な常微分方程式である．
次の題材は，この形に対応させやすい．

| 題材 | 状態変数の例 | モデルの例 | データの例 |
| --- | --- | --- | --- |
| 人口 | 人口 | 指数成長，Logistic，出生率の時間変化 | 国勢調査，人口推計，自治体の統計 |
| 製品普及 | 累積利用者数 | Logistic，模倣と革新の2項モデル | 通信利用動向調査，契約数統計（要確認） |
| ダム貯水量 | 貯水量 | 保存則 $V' = Q_{\mathrm{in}} - Q_{\mathrm{out}}$ | ダム諸量データベース |
| 降水量と河川流量 | タンク貯留量 | タンクモデル $S' = P(t) - kS$ | 気象庁の降水量，水文水質データベース |
| 観光客数 | 月次客数水準の連続時間近似 | 周期的な目標値への緩和 | JNTO，宿泊旅行統計 |
| 電力需要 | 需要 | 周期外力と気温の効果 | 電力会社の使用実績（各自で取得） |
| 生物個体数 | 個体数 | Logistic＋捕獲，Lotka–Volterra | 環境省，水産庁の資源評価（要確認） |
| 感染症 | $S, I, R$ | SIRとその拡張 | 厚生労働省，感染症発生動向調査 |

一方，次の題材は，そのままではこの授業のモデルに対応させにくい．

- **横断面データだけの統計**．ある1時点の都道府県別や年齢別の値には時間軸がなく，変化率を定義できない．
- **地域ランキング**．順位は他の地域との比較で定まる離散的な値であり，本講義の連続時間モデルにそのまま対応させることは難しい．可能なら順位の元となる測定量の時系列を使う．
- **画像や文章**．そのままでは本講義で扱う数値の時系列に対応しない．時間ごとの特徴量を定義して数値化するには，追加の処理とモデル化が必要となる．
- **株価や為替**．時系列ではあるが，変化の主要部分が偶然の変動であり，決定論的な変化率の式で説明できる部分が小さい．確率的なモデルが必要になり，この授業の範囲を超える．

ただし，横断面データを時系列に組み替える（毎年の調査を並べる）ことで題材になる場合もある．
迷ったら計画書の段階で教員に相談する．

## 分析の骨格：Pythonの雛形

レポートのコードは，第7回と第12回のコードを組み合わせたものになる．
次の雛形は，人口データとLogisticモデルを例に，データの読み込み，モデルの定義，シミュレーション，残差の定義，推定，評価，可視化の順に処理を並べたものである．
自分の題材に合わせて，データの列名，右辺の関数，パラメタの初期値と範囲，訓練期間の区切りを書き換える．

```python
# ---------- 1. データの読み込みと前処理（自分の題材に置き換える） ----------
data = pd.read_csv(DATA_DIR / "population_japan.csv")

t_obs = (data["year"] - 1920).to_numpy(dtype=float)                    # 1920年を t = 0 とする [年]
y_obs = (data["total_population_thousand"] / 10).to_numpy(dtype=float)  # 観測量 [万人]

# 訓練期間（推定に使う）と検証期間（推定に使わない）に分ける
train = t_obs <= 70      # 1920〜1990年
valid = ~train           # 1991〜2020年
print(f"訓練期間の点数: {train.sum()}, 検証期間の点数: {valid.sum()}")


# ---------- 2. モデル：仮定を式にした右辺 ----------
def rhs(t, x, r, K):
    """Logisticモデル dN/dt = r N (1 - N/K) の右辺．"""
    return r * x * (1 - x / K)


# ---------- 3. 数値シミュレーション ----------
def simulate(params, t_eval, x0):
    """パラメタ params のもとで，時刻 t_eval における状態変数を返す．"""
    r, K = params
    sol = solve_ivp(rhs, (t_eval[0], t_eval[-1]), [x0], t_eval=t_eval, args=(r, K), rtol=1e-8)
    return sol.y[0]


# ---------- 4. 残差：観測値 − モデル予測 ----------
def residuals(params, t, y, x0):
    """least_squares に渡す残差ベクトル．"""
    return y - simulate(params, t, x0)


# ---------- 5. パラメタ推定（訓練期間のみを使う） ----------
x0 = y_obs[0]                          # 初期条件：最初の観測値
theta0 = [0.02, 15000.0]               # 初期推定値 (r [1/年], K [万人])
lower = [0.0, 5000.0]
upper = [1.0, 50000.0]
result = least_squares(residuals, theta0, args=(t_obs[train], y_obs[train], x0), bounds=(lower, upper))
r_hat, K_hat = result.x
print(f"推定値: r = {r_hat:.4f} /年, K = {K_hat:.0f} 万人, 収束: {result.success}")


# ---------- 6. 評価：訓練期間と検証期間の誤差 ----------
y_model = simulate(result.x, t_obs, x0)
rmse_train = np.sqrt(np.mean((y_obs[train] - y_model[train]) ** 2))
rmse_valid = np.sqrt(np.mean((y_obs[valid] - y_model[valid]) ** 2))
print(f"RMSE 訓練期間: {rmse_train:.1f} 万人, 検証期間: {rmse_valid:.1f} 万人")


# ---------- 7. 可視化：観測値とモデル，残差 ----------
years = 1920 + t_obs
fig, (ax_fit, ax_res) = plt.subplots(2, 1, figsize=(8, 7), sharex=True)
ax_fit.plot(years, y_obs, color="black", marker="o", markersize=3, linestyle="none", label="observed")
ax_fit.plot(years, y_model, linestyle="-", label=f"logistic model (r = {r_hat:.4f}, K = {K_hat:.0f})")
ax_fit.axvline(1990, color="gray", linestyle=":", label="end of training period")
ax_fit.set_title("Model fit and residuals (template)")
ax_fit.set_ylabel("Population [10^4 persons]")
ax_fit.grid(True)
ax_fit.legend()
ax_res.plot(years, y_obs - y_model, marker="o", markersize=3, linestyle="-")
ax_res.axhline(0.0, color="black")
ax_res.axvline(1990, color="gray", linestyle=":")
ax_res.set_xlabel("Year")
ax_res.set_ylabel("Residual [10^4 persons]")
ax_res.grid(True)
fig.tight_layout()
fig.savefig(FIGURE_DIR / "report_template_fit.png", dpi=150)
plt.show()
```

## 自分の言葉で説明する問い

1. データの選択からモデルを検討する経路と，モデルに必要なデータを探す経路は，それぞれどのような長所と短所を持つか．自分の題材ではどちらから始めたか．
2. 自分の題材で，観測量と状態変数はどのように対応しているか．一致しない場合，どのような仮定でつないだか．
3. 株価の時系列は，この授業の決定論的な常微分方程式モデルに向かないとされる．その理由を，変化率を規定する仮定と観測変動の関係を使って説明せよ．
4. モデルがデータに合わなかったとき，レポートには何を書くべきか．観測値との差の報告に加えて記述すべき検討事項を3つ挙げよ．
