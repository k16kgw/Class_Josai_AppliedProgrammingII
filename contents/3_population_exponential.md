## 仮定から式へ：指数成長モデル

### 仮定を言葉で置く

人口の変化について，最も単純な仮定を置く．

**仮定：単位時間あたりの人口の増加量は，現在の人口に比例する．**

この仮定の背景は次のとおりである．
年齢構成などによる違いを無視し，出生・死亡の発生率がそれぞれ人口に比例すると仮定する．
一人あたりの出生率 $b$ と死亡率 $d$ が時間によらず一定なら，十分短い時間 $\Delta t$ の間の出生数と死亡数は，それぞれ $bN\Delta t$ と $dN\Delta t$ で近似できる．

### 式を導く

時刻 $t$ の人口を $N(t)$ とすると，十分短い $\Delta t$ の間の変化量は，人口移動を無視すると近似的に

$$
N(t + \Delta t) - N(t) \approx bN(t)\,\Delta t - dN(t)\,\Delta t = (b - d)\,N(t)\,\Delta t
$$

である．
両辺を $\Delta t$ で割り，$\Delta t \to 0$ とすると，

$$
\frac{dN}{dt} = (b - d)\,N = r\,N,
\qquad r = b - d
$$

を得る．
これが**指数成長モデル**である．
$r$ は一人あたりの純増加率で，出生率と死亡率の差である．

| 項 | 意味 | 単位 |
| --- | --- | --- |
| $N$ | 時刻 $t$ の人口 | 万人 |
| $\dfrac{dN}{dt}$ | 人口の変化率 | 万人／年 |
| $r$ | 一人あたり，1年あたりの純増加率 | 1／年 |
| $rN$ | 1年あたりに増える人数 | 万人／年 |

右辺の単位は $(1/\text{年}) \times \text{万人} = \text{万人}/\text{年}$ で，左辺と一致する．

この式には，出入国，年齢構成，資源の制約は入っていない．
また，$b$ と $d$ が一定という仮定は，出生率が下がり続けている現代の日本には明らかに合わない．
それでもまず最も単純な形で計算し，どこまで説明できるかを見るのがモデリングの進め方である．

### 解析解

初期条件 $N(0) = N_0$ のもとで，このモデルの解は

$$
N(t) = N_0\,e^{rt}
$$

である．
$r > 0$ なら際限なく増え続け，$r < 0$ なら0に向かって減る．

````{dropdown} 補足：解析解を導く

$N' = rN$ を $N$ で割ると $\dfrac{1}{N}\dfrac{dN}{dt} = r$ となる．
左辺は $\dfrac{d}{dt}\ln N$ に等しいので，両辺を $0$ から $t$ まで積分すると

$$
\ln N(t) - \ln N_0 = rt
\quad\Longrightarrow\quad
N(t) = N_0\,e^{rt}
$$

を得る．
途中の式 $\ln N(t) = \ln N_0 + rt$ は，人口の対数が時間の一次式で表されることを示している．
この形は，あとで $r$ をデータから決めるときに使う．
````

## Pythonによる実装：解析解と数値解

右辺の関数と解析解を定義する．
第2回と同じ形で書くが，状態変数の名前を`N`にする．

```python
def exponential_rhs(t, N, r):
    """指数成長モデル dN/dt = r N の右辺．"""
    return r * N


def exponential_solution(t, N0, r, t0=0.0):
    """dN/dt = r N, N(t0) = N0 の解析解 N0 * exp(r (t - t0)) を返す．"""
    return N0 * np.exp(r * (t - t0))
```

観測値を配列として取り出し，時間 $t$ を1920年からの経過年に直す．

```python
year_obs = population["year"].to_numpy()
t_obs = (year_obs - 1920).astype(float)        # 1920年を t = 0 とする [年]
y_obs = population["population_10k"].to_numpy()  # 観測値 [万人]

N0 = y_obs[0]                                   # 初期値：1920年の人口 [万人]
print(f"初期値 N0 = {N0:.1f} 万人")
```

まず，第2回と同じく1920年と1970年の値から $r$ を決める．
$N(50) = N_0 e^{50r}$ が1970年の観測値に一致するように，$r = \ln(y_{1970}/y_{1920}) / 50$ とする．

```python
y_1970 = y_obs[year_obs == 1970][0]
r_two_point = np.log(y_1970 / N0) / 50.0
print(f"2時点法による r = {r_two_point:.5f} /年")
```

この $r$ で解析解と数値解を計算し，一致することを確かめる．

```python
t_span = (0.0, 100.0)                  # 1920年から2020年まで
t_eval = np.arange(0.0, 101.0)         # 1年ごとに出力する

sol = solve_ivp(exponential_rhs, t_span, [N0], t_eval=t_eval, args=(r_two_point,))
N_numeric = sol.y[0]
N_analytic = exponential_solution(t_eval, N0, r_two_point)

print(f"数値解と解析解の最大差: {np.max(np.abs(N_numeric - N_analytic)):.3f} 万人")

fig, ax = plt.subplots(figsize=(7, 4))
ax.plot(1920 + t_eval, N_analytic, color="black", label="analytical solution")
ax.plot(1920 + t_eval, N_numeric, linestyle="--", label="solve_ivp")
ax.set_title(f"Exponential growth model (r = {r_two_point:.4f} /year)")
ax.set_xlabel("Year")
ax.set_ylabel("Population N [10^4 persons]")
ax.grid(True)
ax.legend()
fig.tight_layout()
fig.savefig(FIGURE_DIR / "exponential_analytic_vs_numeric.png", dpi=150)
plt.show()
```

## パラメタをデータから決める

### 2時点法の弱点

2時点法は簡単だが，1920年と1970年の2つの値しか使っていない．
もしどちらかの年の値に特殊な事情があれば，$r$ はその影響を丸ごと受ける．
1920〜1970年の51時点のデータがあるのだから，すべての点を使って $r$ を決めたい．

### 対数線形の最小二乗法

解析解の対数をとると，

$$
\ln N(t) = \ln N_0 + r\,t
$$

となり，$\ln N$ は $t$ の1次式である．
そこで，観測値の対数 $\ln y_i$ を $t_i$ に対して直線で当てはめれば，傾きが $r$，切片が $\ln N_0$ になる．
直線の当てはめには`np.polyfit`が使える．
これは，直線と各点の縦方向の差の2乗和を最小にする直線を求める関数で，**最小二乗法**と呼ばれる方法の最も簡単な場合である．
一般のモデルに対する最小二乗法は第7回で扱う．

```python
# パラメタを決めるのに使う期間
fit_mask = year_obs <= 1970

slope, intercept = np.polyfit(t_obs[fit_mask], np.log(y_obs[fit_mask]), 1)
r_loglinear = slope
N0_loglinear = np.exp(intercept)

print(f"対数線形の最小二乗法による r  = {r_loglinear:.5f} /年")
print(f"同じ方法で決めた N0          = {N0_loglinear:.1f} 万人（観測値は {N0:.1f} 万人）")
print(f"2時点法との差                = {r_loglinear - r_two_point:+.5f} /年")
```

2つの方法で決めた $r$ はいずれもおよそ0.0124で，連続時間の相対増加率を表す．1年間の増加割合は $e^r-1$ で，約1.2%である．
対数線形法では $N_0$ も同時に決まり，1920年の観測値より約50万人大きい値になる．
これは，1920年の観測値そのものを通ることをやめ，50年分の点全体に最も近い直線を選んだためである．

対数をとった図で確かめる．
指数成長が成り立つ期間では，点が直線上に並ぶ．

```python
fig, ax = plt.subplots(figsize=(7, 4))
ax.plot(year_obs, np.log(y_obs), color="black", marker="o", markersize=3, linestyle="none", label="ln(observed)")
ax.plot(year_obs, intercept + slope * t_obs, label=f"least-squares line (r = {r_loglinear:.4f})")
ax.axvline(1970, color="gray", linestyle=":", label="end of fitting period")
ax.set_title("Log of population vs. year")
ax.set_xlabel("Year")
```


### 残差を描く

観測値とモデルの差 $y_i - N(t_i)$ を**残差**と呼ぶ．
重ねた図では小さなずれが見えにくいので，残差を別の図に描く．

```python
residual = y_obs - N_model

fig, ax = plt.subplots(figsize=(8, 3.5))

fig.savefig(FIGURE_DIR / "population_exponential_residual.png", dpi=150)

```

残差の図から次が読み取れる．

- 1920〜1940年：残差は120万人以内で，正負が入れ替わる．モデルはよく合っている
- 1945年前後：残差が大きく負に振れる．戦争と沖縄県の除外という，モデルに入っていない出来事による
- 1950〜1970年：残差は200万人程度以内に戻る
- 1975年以降：残差が単調に負へ広がる．観測値がモデルを下回り続け，2020年には約7000万人の差になる

### 誤差を数値で表す

残差の大きさを1つの数にまとめる指標として，**平均二乗誤差**を使う．

$$
\mathrm{MSE} = \frac{1}{n}\sum_{i=1}^{n}\left(y_i - N(t_i)\right)^2
$$

単位は（万人）$^2$ で，平方根をとれば人口と同じ単位（万人）になる．
以後の回でも同じ関数を使う．

```python
def mean_squared_error(y_obs, y_model):
    """観測値とモデル値の平均二乗誤差を返す．"""
    return np.mean((y_obs - y_model) ** 2)


mse_fit = mean_squared_error(y_obs[fit_mask], N_model[fit_mask])
mse_after = mean_squared_error(y_obs[~fit_mask], N_model[~fit_mask])

print(f"パラメタ決定に使った期間（1920〜1970年）の MSE = {mse_fit:12.1f} （万人）^2，平方根 = {np.sqrt(mse_fit):7.1f} 万人")
print(f"それ以降の期間（1971〜2020年）の MSE           = {mse_after:12.1f} （万人）^2，平方根 = {np.sqrt(mse_after):7.1f} 万人")
```

残差の二乗平均平方根（RMSE）は，パラメタを決めた期間では百数十万人程度だが，その後の期間では数千万人になる．
推定に使用した期間の誤差だけでは，未使用期間の予測精度を評価できない．推定に使用しなかった期間についても誤差を計算する．
この考え方は第7回と第12回で訓練期間と検証期間の区別として本格的に扱う．

````{note} 演習3：図と残差を読む
2. 1945年の残差と2020年の残差は，どちらも負である．原因はどう違うか．データの確認で分かったことを使って説明する．

````

## 未来へ外挿する危険

パラメタを決めた期間の外側にモデルを延ばすことを**外挿**という．
指数成長モデルを2050年まで延ばしてみる．

```python
t_future = np.arange(0.0, 131.0)              # 1920年から2050年まで
N_future = exponential_solution(t_future, N0_loglinear, r_loglinear)

for year in [1970, 2000, 2020, 2050]:
    idx = int(year - 1920)
    line = f"{year}年: モデル {N_future[idx]:9.0f} 万人"
    if year <= 2020:
        line += f"，観測値 {y_obs[year_obs == year][0]:9.0f} 万人"
    print(line)
```

1970年までの50年間でよく合っていたモデルが，2020年には観測値より7000万人近く多い値を，2050年には2億8000万人を超える値を返す．
外挿の期間が長くなるほど，モデルに入っていない要因の影響が積み重なる．

外挿が危険なのは，指数成長モデルが特別に悪いからではない．
推定期間に含まれない政策や人口構成の変化が生じると，推定したパラメタや仮定が適用できなくなる可能性がある．
将来の値を示すときは，モデルの仮定，パラメタの推定期間，外挿する期間を必ず明記する．

## モデルの限界と改善の問い

指数成長モデルは，1920年から1970年までの日本の人口をよく表す．
この期間の当てはまりは純増加率を一定とする近似と整合するが，出生率・死亡率が実際に一定だったことを当てはまりだけから証明することはできない．

1975年以降，観測値はモデルを下回り続け，2008年ごろに頭打ちになり，その後は減少に転じた．
指数成長モデルには，人口が頭打ちになる仕組みも，減少に転じる仕組みも入っていない．
$N_0>0$ のとき，定数 $r$ が正なら単調増加，負なら単調減少，0なら一定であり，増加から減少への転換は生じないためである．

外れる理由として，次のような要因が考えられる．

- 出生率が低下し，$r = b - d$ が一定でなくなった
- 高齢化により死亡率 $d$ が上昇した
- 住宅，雇用，教育費などの制約により，人口が多いほど増え方が鈍る仕組みがある
- 出入国という外部入力を無視している

第4回では，人口の増加に伴って一人あたりの増加率が低下すると仮定し，モデルの式に追加する．
どの仮定を選ぶかは，残差の形から考える．
残差が1975年以降に単調に広がっていることは，相対増加率が推定期間より低下したという解釈と整合する．

## まとめ

- オープンデータを使うときは，出典，単位，期間，欠損や注意すべき年を確認し，記録する．今回のデータでは1945年前後の測り方と，1945〜1971年の沖縄県の除外に注意が必要である
- 人口の変化率が現在の人口に比例するという仮定から $N' = rN$ が導かれる．$r$ は一人あたりの純増加率で，単位は1／年である
- 解析解 $N_0 e^{rt}$ と`solve_ivp`の数値解は一致する．解析解がある場合はこれで数値解を確かめる
- $r$ は2時点法でも決められるが，対数線形の最小二乗法ならすべての点を使える．いずれも1920〜1970年でおよそ0.0124／年になる
- 観測値とモデルの差である残差を図にすると，合う期間と外れる期間，外れ方の向きが分かる
- パラメタを決めた期間の外側への外挿は，期間が長いほど危険である．将来の値には仮定と根拠を添える
